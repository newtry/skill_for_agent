# 实现与代码审查检查表

## 修改前

- [ ] 读取适用的 `AGENTS.md`/`CLAUDE.md`，必要时读取 `AI-DEV-WORKFLOW.md`
- [ ] 记录 `git status --short`，识别用户已有改动
- [ ] 确认模块根目录、依赖方向和目标入口（Admin/App）
- [ ] 找到同类 Controller、Service、DO、Mapper、Convert 和测试
- [ ] 明确不改动的范围、外部契约和数据所有权

## 修改中

- [ ] 遵循 API/Biz 分层，不直接引用兄弟 Biz 实现
- [ ] 复用项目的 `CommonResult`、异常码、逻辑删除、租户和数据权限模式
- [ ] 跨模块只依赖对应 `*-api`；不新增跨模块外键
- [ ] 事务只覆盖必要边界；跨模块一致性显式设计幂等、事件或补偿
- [ ] 对批量、库存、金额、编码生成和导入处理考虑重复、并发、溢出和部分成功
- [ ] 不写入真实密码、Token、JDBC 凭据或生产密钥
- [ ] 使用小而可审查的补丁，不做无关格式化或重构

## 修改后

- [ ] 检查编译、静态检查、测试输出是否真实执行

- [ ] 记录未验证项、环境阻塞和回滚方式
