# DDD Strategy Design Skill

Reusable skill for designing technical solutions from business requirements using DDD strategic design:

- ubiquitous language
- event storming
- subdomain classification
- bounded contexts
- context maps
- aggregate sketches
- implementation mapping

## Local Install

Use this directory as the single source and link it into both tools:

```bash
ln -s /path/to/ddd-strategy-design ~/.claude/skills/ddd-strategy-design
ln -s /path/to/ddd-strategy-design ~/.codex/skills/ddd-strategy-design
```

## Invocation

```text
Use $ddd-strategy-design to analyze this business requirement: ...
```
