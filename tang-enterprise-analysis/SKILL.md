# 唐朝企业分析技能

## 核心思想

**买股票就是买公司，买公司就是买其未来现金流的折现。**

## 唐朝三问（核心检验）

任何企业分析必须回答：

| 问题 | 检验内容 | 关键指标 |
|------|---------|---------|
| 这个生意赚钱吗？ | 盈利能力 | 毛利率>40%、净利率>15%、ROE>15% |
| 赚的是真钱吗？ | 利润质量 | 经营现金流/净利润≥1、应收账款/营收<30% |
| 能持续赚钱吗？ | 可持续性 | 护城河宽度、行业地位、管理层诚信 |

## 分析工作流

```
ROE筛选 → 商业模式 → 护城河 → 管理层 → 财报解读 → 估值 → 投资决策
```

### Step 1: ROE筛选（路标）

| ROE水平 | 评级 | 操作建议 |
|---------|------|---------|
| ≥30% | 顶级 | 唐朝重仓标准 |
| ≥20% | 优秀 | 重点关注 |
| ≥15% | 良好 | 可纳入观察 |
| <10% | 一般 | 通常不考虑 |

**筛选条件**：过去5年ROE持续≥15%、经营现金流≥净利润、有息负债低

### Step 2: 商业模式分析

**定性分析**：
- 核心业务识别：一句话能否说清楚？
- 盈利模式：毛利率、净利率、ROE来源（高净利率驱动最优）
- 业务持续性：行业生命周期、技术迭代风险

**定量评分**：详见 [references/business_model_analysis.md](references/business_model_analysis.md)

### Step 3: 护城河分析

| 护城河类型 | 评分 | 代表企业 |
|-----------|------|---------|
| 品牌垄断 | 40分 | 茅台 |
| 网络效应 | 35分 | 腾讯 |
| 成本优势 | 30分 | 沃尔玛 |
| 技术专利 | 25分 | 医药企业 |

### Step 4: 管理层分析

评估维度：诚信、能力、股东回报意识、资本配置能力。

**核心管理层必查项**：
- 关键人物：实际控制人、董事长、CEO/总经理、CFO、核心业务负责人是谁，是否长期稳定，是否理解并深度参与主业。
- 经营记录：任期内收入、利润、ROE、现金流、市场份额和核心资产是否持续改善；不要只看口号，要用结果验证能力。
- 资本配置：是否聚焦主业，是否做过高价并购、跨界投资、低回报投资、频繁减值；分红、回购和再投资是否理性。
- 股东利益一致性：管理层和大股东持股、增减持、股权激励、分红政策是否与中小股东一致。
- 诚信和治理：信息披露是否清晰，关联交易、资金占用、违规处罚、业绩承诺失信、财务重述等记录是否存在。
- 接班和组织能力：公司是否依赖单一强人，核心团队是否稳定，战略执行是否连续。

管理层分析必须结合事实和数据，不得只写“管理层优秀”。必须回答：这届管理层过去是否创造了股东价值，是否守住能力圈，是否把资本投向能增强核心资产和未来盈利能力的地方。

### Step 5: 财报解读

**利润质量核心指标**：

| 指标 | 优秀 | 良好 | 危险 |
|-----|------|------|------|
| 经营现金流/净利润 | >1.2 | 1.0-1.2 | <0.5 |
| 销售现金/营业收入 | >1.1 | 1.0-1.1 | <0.9 |
| 扣非净利润/净利润 | >0.9 | 0.8-0.9 | <0.6 |
| 应收账款/营业收入 | <10% | 10-30% | >30% |

**地雷扫描**：
- 其他应收款/总资产 > 10% → 高风险
- 商誉/总资产 > 30% → 减值风险
- 经营现金流为负但净利润为正 → 纸面富贵

**核心资产与资产质量必查项**：
- 核心经营资产：先识别公司真正依靠什么资产赚钱，如品牌、渠道、客户关系、点位网络、牌照、产能、技术平台、用户网络、金融资产等；说明这些资产是否在资产负债表内，是否被低估或高估。
- 资产盈利能力：分析核心资产如何转化为收入、毛利、经营现金流和自由现金流；优先使用资产周转率、固定资产周转率、投入资本回报率(ROIC)、ROA、单点位/单门店/单用户产出等指标。
- 资产可持续性：判断核心资产是否需要持续大量资本开支维护，是否会被技术替代、竞争复制、政策削弱或客户迁移。
- 货币资金：是否充足，是否与有息负债矛盾，是否存在受限资金或收益率异常。
- 应收账款/合同资产：占营收比例、账龄、坏账准备、增速是否超过营收增速。
- 存货：周转率、跌价准备、增速是否超过营收增速；结合行业属性判断是否真的有价值。
- 商誉和长期股权投资：占净资产比例，是否存在减值风险，投资收益是否稳定可靠。
- 固定资产、使用权资产和资本开支：是否需要持续投入才能维持盈利，自由现金流是否被侵蚀。
- 负债结构：有息负债、租赁负债、合同负债、或有负债，判断偿债压力和真实经营杠杆。

资产质量分析必须独立成段，不得只放在风险提示里一笔带过。必须先回答“这家公司真正赚钱的核心资产是什么”，再回答这些资产“是否真实、是否高效、是否能持续产生现金流”。每个高占比资产科目都要回答：它是不是能产生现金流的好资产，未来盈利能力会增强还是衰减，是否可能减值，是否隐藏关联方占款或坏账。

详细方法见 [references/profit_quality_analysis.md](references/profit_quality_analysis.md)

### Step 6: 估值计算

**自由现金流折现法**：

```
FCF = 经营现金流 - 资本开支
内在价值 = Σ(未来FCF折现) + 永续期价值
买入价 = 内在价值 × 50%
卖出价 = 内在价值 × 150%
```

**企业分类估值参数**：

| 企业类型 | 预测期 | 增长率 | 折现率 | 永续增长率 |
|---------|--------|--------|--------|-----------|
| 稳定成长型（茅台） | 10年 | 10%→5% | 10% | 3% |
| 周期性（银行） | 7年 | 5%-8% | 10% | 3% |
| 成长型（腾讯） | 8年 | 15%→10% | 12% | 4% |

详细方法见 [references/valuation_methods.md](references/valuation_methods.md)

### Step 7: 投资决策

**买入检查清单**：
- [ ] 过去5年ROE持续≥15%
- [ ] 商业模式简单易懂
- [ ] 有明显护城河
- [ ] 管理层诚信、能力出众
- [ ] 经营现金流≥净利润
- [ ] 价格低于内在价值50%

**卖出标准**：基本面恶化、价格超过内在价值150%、发现更好标的、发现判断错误

## 数据获取方式

### 方式一：自动下载年报（推荐）

使用内置的年报下载器从巨潮资讯网自动下载年报PDF：

**Python API方式**：

```python
from scripts.cninfo_report_downloader import CNINFODownloader

downloader = CNINFODownloader("./annual_reports")

# 下载A股年报（支持股票代码、名称、拼音）
files = downloader.download_annual_reports('贵州茅台', years=[2021, 2022, 2023, 2024])

# 下载港股年报（腾讯控股）
files = downloader.download_annual_reports('00700', years=[2021, 2022, 2023, 2024])

# 下载季报（Q1、半年报、Q3）
files = downloader.download_quarterly_reports('贵州茅台', year=2024)
```

**命令行方式**：

```bash
# 下载多年年报
python scripts/cninfo_report_downloader.py 贵州茅台 --years 2021,2022,2023,2024 --output-dir ./reports

# 下载港股报告
python scripts/cninfo_report_downloader.py 00700 --years 2021,2022,2023,2024 --output-dir ./腾讯控股报告

# 下载季报
python scripts/cninfo_report_downloader.py 贵州茅台 --quarterly --year 2024
```

**支持的股票类型**：
- A股：支持股票代码（000001）、公司名称（平安银行）、拼音缩写（payh）
- 港股：支持5位港股代码（00700腾讯、00175吉利）

请用户提供以下关键数据（单位：亿元）：
- 营业收入、毛利润、净利润、扣非净利润
- 经营现金流、销售收到的现金
- 应收账款、存货、总资产、净资产
- 资本开支

### 方式三：从PDF年报提取

使用 `scripts/pdf_data_extractor.py` 从PDF年报提取数据。

## 输出格式规范

### 报告写作要求

生成个股分析报告时，先形成清晰的核心投资判断，再组织证据。不要把报告写成指标清单。

必须遵守：
- 开头先用3-5段连续文字给出摘要判断，回答：这家公司是不是好生意、好在哪里、主要风险是什么、当前价格是否有吸引力。
- 正文以连续分析段落为主，表格只用于承载关键数据。每张表格后必须至少写一段解释，说明这些数据证明了什么、反驳了什么、还不能证明什么。
- 每个核心章节按“判断 -> 证据 -> 解释 -> 风险 -> 小结”组织。
- 不允许只罗列ROE、毛利率、现金流、估值等指标；任何关键数据后都必须解释其商业含义和投资含义。
- 必须单列核心资产与资产质量分析，先识别真正带来盈利的核心资产，再分析这些资产如何转化为收入、利润和自由现金流；同时检查货币资金、应收账款/合同资产、存货、商誉、长期股权投资、固定资产/使用权资产、有息负债和其他应收款。不得用“财报风险”替代资产质量。
- 必须单列核心管理层与资本配置分析，评估关键人物、历史经营记录、资本配置、股东回报、激励一致性和治理风险；不得只用“管理层诚信/优秀”一句话带过。
- 估值部分必须说明关键假设为什么合理、哪些假设最脆弱、估值结论适用于什么前提。
- 结尾必须给出完整投资结论：企业质量、财报质量、估值吸引力、适合的投资者、买入/持有/回避条件。

### 企业分析报告结构

```markdown
# [公司名称] 投资分析报告

## 摘要判断
用3-5段连续文字说明最终判断，不用表格。

## 一、这家公司到底是不是一门好生意
先写业务本质，再用ROE、毛利率、净利率证明赚钱能力，并解释这些指标背后的商业含义。

## 二、利润是不是真金白银
用经营现金流、销售现金、应收账款、扣非利润解释利润质量；数据之后必须给出判断。

## 三、核心资产与资产质量
独立分析资产负债表。先识别公司真正依靠什么核心资产赚钱，并说明这些资产如何带来收入、利润和自由现金流；再分析核心资产的产出效率和可持续性。重点检查货币资金、应收账款/合同资产、存货、商誉、长期股权投资、固定资产/使用权资产、其他应收款和有息负债。判断资产是否真实、是否高效、是否能支撑未来盈利，是否可能减值或隐藏占款、坏账。

## 四、护城河能不能保护未来收益
分析品牌、网络效应、成本优势、牌照、转换成本、行业格局和管理层，不只列护城河类型。

## 五、核心管理层与资本配置
分析实际控制人、董事长、CEO/总经理、CFO和核心业务负责人。用历史经营结果、资本配置、分红回购、并购减值、股权激励、增减持、关联交易和违规记录来判断管理层是否可信、能干、是否与股东利益一致。

## 六、财报里有没有需要排除的风险
重点分析异常科目、现金流背离、商誉、负债、关联交易、审计意见和不合商业逻辑之处。

## 七、估值是否提供安全边际
说明自由现金流、增长率、折现率、永续增长率和股本假设，并给出内在价值、买入价、卖出价。

## 八、最终投资结论
给出“值得深入研究/等待价格/谨慎/回避”的判断，以及买入、持有、卖出或回避的触发条件。
```
