# 企业分析

## 核心原则

把股票视为企业所有权，把估值视为未来可分配现金流的折现。先理解生意，再核验财务，最后讨论价格。

执行时遵守以下原则：

- 用证据形成判断，不用指标数量制造确定感。
- 将已披露事实、计算结果和分析假设明确分开。
- 将财务变化翻译为产品、客户、价格、销量、渠道、成本、竞争和资本配置的变化。
- 按行业选择指标和估值方法，不使用跨行业统一及格线。
- 数据不足时缩小结论范围；关键数据缺失时停止精确估值。
- 输出研究判断和触发条件，不承诺收益，不替用户作个性化投资决定。

## 选择任务模式

先按用户意图选择最小充分模式，不要每次都生成完整报告：

| 模式 | 适用请求 | 必须完成 |
|---|---|---|
| 完整分析 | “分析某公司”“是否值得投资” | 生意、财务、资产、管理层、护城河、风险、估值 |
| 专项分析 | 利润质量、ROE、现金流、管理层等 | 回答专项问题及其必要上下游，不扩写无关章节 |
| 估值 | DCF、内在价值、买入区间 | 验证方法适用性、列示假设、情景和敏感性 |
| 筛选 | ROE或其他条件选股 | 定义口径、行业分组、筛选后复核项 |
| 方法解释 | 概念或框架问题 | 解释原理、边界和简短示例，不虚构实时数据 |

## 执行工作流

### 1. 明确研究对象和时点

确认公司全称、代码、上市地、报告币种、分析截止日期和用户要求的期间。同名、跨市场或多上市主体存在歧义时先澄清。

### 2. 识别企业类型

先分类，再选指标和估值方法：

- 普通非金融企业：消费、制造、互联网、软件、医药、公用事业等。
- 金融企业：银行、保险、券商。必须读取 [金融企业分析](references/financial_institutions.md)，不得套用普通企业经营现金流DCF。
- 强周期或资源企业：读取 [周期企业分析](references/cyclical_companies.md)，使用周期中枢盈利、资产负债表和供需位置，不使用周期顶部单年利润外推。
- 亏损、困境反转或早期成长企业：优先讨论生存能力、融资需求和情景概率；现金流不可预测时不得给伪精确DCF。

### 3. 建立可追溯数据包

必须读取并执行 [数据质量规范](references/data_quality.md)。优先使用交易所公告、公司审计年报和公司投资者关系材料。

每个关键数字至少记录：数值、单位、期间、合并/母公司口径、来源文件和页码或链接。标记其类型：

- `reported`：原始披露数据。
- `calculated`：由披露数据计算，列出公式。
- `assumption`：预测或估值假设，说明依据。

以下情况不得继续精确估值：公司身份不确定；关键报表口径不一致；自由现金流、净资产、股本等核心输入缺失；PDF自动提取结果未经交叉核验；当前价格没有日期和来源。

### 4. 理解生意

用业务语言回答：卖什么、卖给谁、客户为何购买、收入如何确认、关键成本是什么、增长来自哪里、维持竞争力需要多少增量资本。

ROE、毛利率和净利率只作为路标。必须结合行业、历史区间、同行和杜邦分解解释来源。高ROE若来自高杠杆、低净资产或一次性收益，不等同于高质量。

商业模式的详细检查项见 [商业模式分析](references/business_model_analysis.md)。按需搜索对应行业或指标章节，不要整篇加载。

### 5. 核验利润和资产

对普通非金融企业至少检查：

- 归母净利润与扣非归母净利润的差异。
- 经营现金流与利润的长期匹配，而非只看单年比值。
- 应收、合同资产、存货、商誉、长期股权投资、固定资产、使用权资产和有息负债。
- 维持性资本开支、营运资金占用和自由现金流。
- 审计意见、关联交易、资金占用、担保、减值和会计政策变化。

先识别真正产生收益的核心资产，再判断其真实性、产出效率、资本需求和衰减风险。详细方法见 [财报、利润与资产质量](references/financial_statement_analysis.md)。

### 6. 评估护城河和管理层

护城河必须由可观察结果验证，例如持续的价格权、留存率、单位成本优势、网络密度、转换成本、牌照稀缺性或长期市场份额。不要给品牌、技术等标签分配固定绝对分数。

管理层至少核查实际控制人、董事长、CEO/总经理、CFO、任期、经营记录、并购与减值、分红回购、增减持、股权激励、关联交易、处罚和接班风险。区分管理层能力、诚信和股东利益一致性，并用事实支持。详细方法见 [管理层与资本配置](references/management_capital_allocation.md)。

### 7. 选择估值方法

普通企业优先使用标准化自由现金流：

```text
FCFF = EBIT × (1 - 税率) + 折旧摊销 - 资本开支 - 营运资金增加
股权价值 = 企业价值 + 非经营性资产 - 有息负债 - 少数股东权益
```

经营现金流减资本开支可作简化近似，但必须说明它混入融资结构、营运资金波动及增长性资本开支的限制。

估值至少给出保守、基准、乐观三种情景，并展示增长率、利润率或现金转化率、折现率、永续增长率、净债务和股本的敏感性。永续增长率必须低于折现率。买入区间取决于不确定性和所需安全边际；不得机械规定所有公司均为内在价值50%，也不得把150%内在价值作为自动卖出指令。

详细公式和适用边界见 [估值方法](references/valuation_methods.md)。计算普通企业DCF时调用 `scripts/valuation_calculator.py`，不要手算长序列。

### 8. 形成结论

结论必须同时说明：企业质量、财报可信度、估值吸引力、最关键假设、主要反方证据，以及买入、继续观察、持有、降低判断或回避的触发条件。

使用条件式表达，例如“若A保持且价格低于B，则……；若C发生，则原判断失效”。数据不足时给待核查清单，不用虚构数字补齐模板。

## 数据工具

- A股公告下载：`scripts/cninfo_report_downloader.py`。当前仅支持脚本内登记的代码或名称，不支持任意股票或拼音。
- 港股公告下载：`scripts/hkex_report_downloader.py`。传入五位或可补齐为五位的港股代码和报告年度；先用 `--list-only` 核对标题、年度、发布日期和URL，再下载PDF。
- PDF提取：`scripts/pdf_data_extractor.py`。港股字段来自 `references/hkfrs_field_mapping.json`；金额统一为报告币种的1亿单位，股份统一为绝对股数。遇到裸 `$m` 时必须从年报确认币种并显式传入 `reporting_currency`。提取结果仅作候选数据，必须对照原表、单位、期间和合并口径复核。
- 历史趋势：`scripts/historical_data_analyzer.py`。
- 利润质量：`scripts/profit_quality_analyzer.py`。只把输出当作异常线索；不得在报告中把综合分数作为企业质量结论。
- 估值计算：`scripts/valuation_calculator.py`。仅用于适用普通企业的现金流模型及明确支持的金融模型。

不要因为工具返回 `0`、空列表或默认参数就假设数据真实存在。运行脚本前统一金额单位；股本和金额必须使用兼容量纲。

## 输出规范

完整报告使用以下结构；专项任务只保留相关章节：

```markdown
# [公司名称] 投资分析报告

## 摘要判断
## 一、业务与盈利模式
## 二、利润真实性与财务趋势
## 三、核心资产与资产质量
## 四、竞争优势及其证据
## 五、管理层与资本配置
## 六、反方证据与待核查事项
## 七、估值情景与安全边际
## 八、结论及失效条件
## 数据来源与口径
```

开头用连续文字给出核心判断。表格只承载可比较数据，每张表后解释其证明了什么、不能证明什么。正文不暴露方法来源名称，除非用户明确要求解释该方法。
