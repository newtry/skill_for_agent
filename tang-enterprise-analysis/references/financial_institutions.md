# 金融企业分析与估值

## 1. 为什么不能套用普通企业DCF

银行和多数金融机构的负债是经营原料，经营现金流受存贷款、同业和投资资产变化影响，资本开支也不是约束可分配现金的主要变量。因此不要用“经营现金流减资本开支”估算银行自由现金流。

金融企业的核心约束是监管资本、资产质量、负债成本、风险承担和可分配利润。先判断资产与资本的真实性，再估值。

## 2. 银行

### 2.1 生意与质量指标

至少分析：

- 净利息收入、非息收入和收入结构。
- 净息差及其变化原因：资产收益率、存款成本、负债结构和重定价周期。
- 不良贷款率、关注类贷款、逾期贷款及迁徙率。
- 拨备覆盖率、贷款拨备率和信用成本。
- 核心一级资本充足率、资本充足率和风险加权资产增速。
- 存款基础、活期占比、客户集中度和流动性。
- ROA、ROE及杠杆来源。
- 房地产、地方融资平台、信用卡等重点风险暴露。

不要仅凭低不良率判断资产优良；结合核销、重组、逾期、关注类贷款和拨备变化判断确认是否滞后。

### 2.2 银行估值

优先使用剩余收益模型并用PB-ROE交叉验证：

```text
剩余收益_t = 净利润_t - 期初普通股净资产_t × 股权成本
股权价值 = 当前普通股净资产 + 未来剩余收益现值
```

只有分红政策稳定且监管资本充足时，才使用股利折现模型：

```text
股权价值 = 未来可持续股利的折现值
```

关键假设包括正常化ROE、信用成本、净息差、资本充足率、分红率、股权成本和长期增长率。PB不是越低越便宜；低PB可能反映低ROE、资产质量或资本缺口。

## 3. 保险

至少分析：

- 寿险新业务价值、新业务价值率、内含价值及营运经验差异。
- 保费结构、退保率、继续率、费用率和渠道质量。
- 财险综合成本率及大灾波动。
- 投资资产结构、久期匹配、信用风险和投资收益质量。
- 偿付能力充足率和资本补充需求。

估值以调整后净资产、内含价值和新业务价值为核心。不要把短期投资收益直接资本化，也不要对内含价值机械套固定倍数。

## 4. 券商

至少分析：

- 经纪、投行、资管、信用和自营业务结构。
- 自营资产风险、方向性敞口和公允价值波动。
- 两融、股票质押、场外衍生品和信用减值风险。
- 净资本、风险覆盖率和杠杆水平。
- 跨周期ROE和费用控制。

使用正常化利润、跨周期ROE和PB估值。对牛市高利润做均值回归，不用单年利润外推。

## 5. 通用治理风险

金融企业额外核查：

- 关联方授信、股东质押、资金占用和利益输送。
- 监管处罚、内部控制缺陷和风险事件。
- 表外业务、或有负债和复杂结构化产品。
- 激进扩张、资本补充频率和股权稀释。
- 管理层风险偏好是否与长期股东利益一致。

结论必须说明资产质量判断最可能在哪些情景下失效。
