# 金融企业分析与估值

## 目录

1. 方法边界
2. 银行
3. 保险
4. 券商
5. 治理与共同风险

## 1. 方法边界

金融企业的负债通常是经营原料，经营现金流受存贷款、保费、投资和同业业务变化影响。资本开支也不是约束可分配现金的主要变量。

不要用“经营现金流减资本开支”估算银行、保险或券商自由现金流。核心约束是资产质量、监管资本、风险承担和可分配利润。

## 2. 银行

### 2.1 盈利结构

检查：

- 净利息收入、手续费及其他非息收入。
- 净息差、资产收益率、存款成本和重定价周期。
- ROA、ROE及杠杆来源。
- 成本收入比和数字化投入。

净息差变化必须拆成资产端、负债端、结构和市场利率影响。

### 2.2 资产质量

至少分析：

- 不良、关注、逾期贷款及迁徙率。
- 核销、重组、展期和不良确认政策。
- 拨备覆盖率、贷款拨备率和信用成本。
- 房地产、地方融资平台、信用卡和重点行业暴露。
- 单一客户、地区和关联方集中度。

低不良率不自动等于资产优良。结合关注和逾期迁徙、核销、拨备与宏观环境判断确认是否滞后。

### 2.3 负债与资本

检查存款基础、活期占比、客户集中、同业融资、流动性覆盖率、核心一级资本和风险加权资产增速。高增长如果持续消耗资本，可能需要降低分红或融资。

### 2.4 估值

优先使用剩余收益模型：

```text
剩余收益_t = 净利润_t - 期初普通股净资产_t × 股权成本
股权价值 = 当前普通股净资产 + 未来剩余收益现值
```

关键假设包括正常化ROE、净息差、信用成本、资本要求、分红率、股权成本和长期增长。用PB-ROE交叉验证。

只有分红政策可持续且资本缓冲充足时才使用股利折现：

```text
股权价值 = 未来可持续股利现值
```

低PB可能反映低ROE、资产风险或资本缺口，不自动代表低估。

## 3. 保险

### 3.1 寿险

检查新业务价值、新业务价值率、内含价值、继续率、退保率、产品结构、渠道质量和费用假设。区分经营经验差异、假设调整和市场波动对内含价值的影响。

### 3.2 财险

检查综合成本率、赔付率、费用率、准备金发展和大灾波动。短期低赔付可能来自偶然因素或准备金释放。

### 3.3 投资与资本

分析投资资产结构、久期匹配、信用风险、未实现损益、投资收益可重复性和偿付能力。不要把短期资本市场收益永久化。

估值以调整后净资产、内含价值和可持续新业务价值为核心，并对利率、权益市场、退保和偿付能力做情景分析。

## 4. 券商

分解经纪、投行、资管、信用、自营和衍生品业务。检查：

- 收入对成交额、发行市场和资产价格的敏感性。
- 自营方向性敞口、公允价值和尾部风险。
- 两融、股票质押、场外衍生品和信用减值。
- 净资本、风险覆盖率和融资结构。
- 跨周期ROE、费用和分部资本占用。

使用正常化利润、跨周期ROE和PB估值。不要用牛市单年利润外推。

## 5. 治理与共同风险

额外核查：

- 关联方授信、股东质押、资金占用和利益输送。
- 监管处罚、内部控制缺陷和重大风险事件。
- 表外业务、或有负债和复杂结构化产品。
- 激进扩张、资本补充频率和股权稀释。
- 管理层激励是否鼓励短期规模或过度风险承担。

## 6. 输出要求

结论至少包括：

- 盈利来源及其周期性。
- 资产质量和确认滞后风险。
- 监管资本与分红能力。
- 适用估值方法及关键假设。
- 压力情景、反方证据和判断失效条件。
