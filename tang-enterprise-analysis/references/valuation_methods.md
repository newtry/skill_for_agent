# 估值方法详解和案例分析

> 本文案例数字仅用于演示计算结构，不代表当前数据或当前估值。实际分析必须重新取数并标注来源、日期和口径。

## 1. 自由现金流折现法（DCF）基础

### 1.1 基本原理
- **核心思想**：企业的内在价值等于其未来产生的自由现金流的现值之和。
- **适用条件**：企业具有稳定的现金流，未来发展可预测性强。
- **优势**：理论上最科学的估值方法，反映企业的真实价值。
- **局限性**：对未来预测依赖较强，计算复杂度较高。

### 1.2 自由现金流（FCF）计算
- **企业自由现金流**：FCFF = EBIT ×（1 - 税率）+ 折旧摊销 - 资本开支 - 营运资金增加。
- **股权自由现金流**：FCFE = 净利润 + 折旧摊销 - 资本开支 - 营运资金增加 + 净借款。
- **简化近似**：经营现金流 - 资本开支。仅在口径清楚、营运资金波动可解释时使用。
- **注意事项**：
  - 分红是对股东的回报，不应从自由现金流中扣除
  - 分红是自由现金流的使用方式之一，而不是经营的必要支出
  - 需排除非经常性损益的影响，使用扣除非经常性损益后的净利润
  - 当企业满足3大前提的情况下，可直接使用净利润作为FCF (3大前提为：利润为真，可持续，无需大量资本支出来维持当前盈利)

## 2. 自由现金流折现简化版

### 2.1 估值步骤

#### Step 1: 确定基准年自由现金流
- **选择基准年**：通常选择最近一年的财务数据作为基准。
- **计算FCF**：使用上述公式计算基准年自由现金流。
- **调整非经常性项目**：排除一次性损益、政府补助等非经常性项目的影响。

#### Step 2: 预测未来现金流
- **预测期**：通常为5-10年，根据企业发展阶段调整。
- **增长率假设**：
  - 成长期企业：可假设较高增长率（如15%-25%）。
  - 成熟期企业：假设较低增长率（如5%-10%）。
  - 周期性企业：需考虑行业周期，使用周期平均增长率。
- **永续增长期**：预测期结束后，企业进入永续增长期，增长率通常假设为3%-5%（接近无风险利率）。

#### Step 3: 确定折现率
- **无风险利率**：通常使用10年期国债收益率作为参考（如3%-4%）。
- **风险溢价**：根据企业所在行业的风险程度调整（如2%-4%）。
- **折现率计算公式**：折现率 = 无风险利率 + 风险溢价
- **实践建议**：为简化计算，成熟稳定企业通常可先用10%作为折现率基准，再根据行业风险和企业质量调整。

#### Step 4: 计算现值
- **预测期现值**：将预测期内每年的自由现金流按折现率折现到基准年。
- **永续期现值**：使用戈登增长模型计算永续期自由现金流的现值。
  - 公式：永续期现值 = 预测期最后一年FCF ×（1 + 永续增长率）/（折现率 - 永续增长率）
- **企业内在价值**：预测期现值 + 永续期现值

#### Step 5: 确定买入/卖出价格
- **买入区间**：根据保守、基准、乐观情景和估值不确定性设置安全边际，不使用跨公司统一折扣。
- **退出条件**：结合基本面失效、机会成本、税费和显著高估判断，不把内在价值固定倍数作为自动卖出指令。

### 2.2 估值参数调整

#### 增长率调整
- **基于历史业绩**：分析企业过去3-5年的收入和利润增长率。
- **基于行业空间**：考虑行业整体增长潜力和企业市场份额变化。
- **基于竞争格局**：评估企业竞争优势对未来增长的支撑作用。
- **保守原则**：宁可低估增长率，也不高估，避免过度乐观。

#### 折现率调整
- **企业风险**：高风险企业（如科技股）使用较高折现率，低风险企业（如消费股）使用较低折现率。
- **行业风险**：周期性行业（如钢铁、化工）使用较高折现率，稳定行业（如白酒、医药）使用较低折现率。
- **宏观环境**：利率上升周期使用较高折现率，利率下降周期使用较低折现率。

#### 永续增长率调整
- **经济增长**：通常不超过GDP增长率。
- **行业增长**：考虑行业长期增长趋势。
- **企业自身**：评估企业长期竞争力和增长潜力。

## 3. 企业分类与估值策略

### 3.1 稳定成长型企业
- **特征**：业务稳定，增长可预测，现金流充足，如茅台、可口可乐。
- **估值方法**：使用自由现金流折现法，假设较长的预测期（如10年）和较低的永续增长率（如3%-4%）。
- **注意事项**：关注企业的品牌价值和护城河，确保长期增长的可持续性。

### 3.2 周期性企业
- **特征**：业务受商品价格或产能周期影响较大，盈利波动剧烈，如钢铁、化工、航运和资源企业。
- **估值方法**：使用周期均值法，取一个完整周期的平均利润作为基准。
- **注意事项**：需识别行业周期的底部和顶部，避免在周期顶部高估企业价值。

银行、保险和券商不是普通周期企业。其现金流与资本约束不同，必须使用 [金融企业分析](financial_institutions.md) 中的专门方法。

### 3.3 困境反转型企业
- **特征**：当前经营困难，但有反转潜力，如某些处于行业低谷的龙头企业。
- **估值方法**：谨慎使用DCF，需评估反转概率和时间，可结合清算价值法。
- **注意事项**：反转不确定性高，通常不纳入核心持仓，仓位控制在10%以内。

### 3.4 成长股
- **特征**：高增长，高估值，如新兴科技企业。
- **估值方法**：使用DCF，但需更保守的增长率假设，关注企业的商业模式和护城河。
- **注意事项**：高增长往往伴随高风险，需严格控制仓位，避免追高。

## 4. 相对估值法

### 4.1 市盈率（PE）
- **公式**：PE = 股价 / 每股收益
- **适用条件**：盈利稳定的企业，如消费股、医药股。
- **注意事项**：需使用扣除非经常性损益后的市盈率，与行业平均水平对比。

### 4.2 市净率（PB）
- **公式**：PB = 股价 / 每股净资产
- **适用条件**：净资产能够反映主要经营资本的企业。金融企业必须同时核验资产质量、监管资本和可持续ROE。
- **注意事项**：关注企业的资产质量，避免资产高估的企业。

### 4.3 市销率（PS）
- **公式**：PS = 股价 / 每股销售收入
- **适用条件**：尚未盈利的成长型企业，如部分科技股。
- **注意事项**：需结合企业的毛利率和费用率变化趋势分析。

### 4.4 市现率（PCF）
- **公式**：PCF = 股价 / 每股经营现金流
- **适用条件**：现金流稳定的企业，可作为DCF的辅助指标。
- **注意事项**：关注经营现金流与净利润的匹配度。

## 5. 估值案例分析

### 5.1 茅台估值案例

#### 步骤1: 确定基准年自由现金流
- **基准年**：2023年
- **经营活动现金流量净额**：约666亿元
- **资本开支**：约40亿元
- **基准年FCF**：666 - 40 = 626亿元

#### 步骤2: 预测未来现金流
- **预测期**：10年（2024-2033）
- **增长率假设**：前5年10%，后5年5%
- **永续增长率**：3%

#### 步骤3: 确定折现率
- **折现率**：10%

#### 步骤4: 计算现值
- **预测期现值**：计算2024-2033年各年FCF的现值之和。
- **永续期现值**：2033年FCF ×（1 + 3%）/（10% - 3%），再折现到2023年。
- **内在价值**：预测期现值 + 永续期现值 ≈ 15000亿元
- **每股内在价值**：15000亿元 / 12.56亿股 ≈ 1194元

#### 步骤5: 确定买入/卖出价格
- **历史规则演示**：原方法以50%内在价值作为极保守买入参考、150%作为高估参考。
- **实际使用**：根据情景区间、估值误差和基本面失效条件确定，不机械沿用固定倍数。

### 5.2 腾讯估值案例

#### 步骤1: 确定基准年自由现金流
- **基准年**：2023年
- **净利润**：约1500亿元（扣除非经常性损益后）
- **分红率**：约30%
- **基准年FCF**：1500 ×（1 - 30%）= 1050亿元

#### 步骤2: 预测未来现金流
- **预测期**：8年（2024-2031）
- **增长率假设**：前4年15%，后4年10%
- **永续增长率**：4%

#### 步骤3: 确定折现率
- **折现率**：10%

#### 步骤4: 计算现值
- **预测期现值**：计算2024-2031年各年FCF的现值之和。
- **永续期现值**：2031年FCF ×（1 + 4%）/（10% - 4%），再折现到2023年。
- **内在价值**：预测期现值 + 永续期现值 ≈ 30000亿元
- **每股内在价值**：30000亿元 / 91.9亿股 ≈ 326元

#### 步骤5: 确定买入/卖出价格
- **历史规则演示**：固定折扣可用于展示安全边际概念，但不是当前结论。
- **实际使用**：按情景区间和关键假设脆弱性设置安全边际与退出条件。

### 5.3 银行估值示例框架

不要从银行经营现金流推导FCF。使用剩余收益模型：

1. 取得估值时点普通股净资产，并核验资产质量和资本充足率。
2. 按净息差、信用成本和资本约束预测正常化ROE。
3. 计算每期剩余收益：期初普通股净资产 ×（ROE - 股权成本）。
4. 折现明确预测期剩余收益和终值，再加当前普通股净资产。
5. 用可持续ROE与PB关系、股利折现结果交叉验证。

模型必须展示正常化ROE、信用成本、分红率、股权成本和长期增长率的敏感性。完整要求见 [金融企业分析](financial_institutions.md)。

## 6. 估值常见误区

### 6.1 过度乐观的增长率假设
- **表现**：假设企业未来增长率持续高于历史水平或行业平均水平。
- **风险**：导致内在价值高估，买入价格过高，投资回报率下降。
- **规避方法**：使用保守的增长率假设，参考行业平均水平和企业历史表现。

### 6.2 忽略非经常性损益
- **表现**：使用包含非经常性损益的净利润计算FCF。
- **风险**：高估企业的真实盈利能力，导致估值偏高。
- **规避方法**：使用扣除非经常性损益后的净利润，关注企业的核心盈利能力。

### 6.3 折现率选择不当
- **表现**：使用过低的折现率，未考虑企业风险。
- **风险**：高估企业内在价值，承担不必要的风险。
- **规避方法**：根据企业风险和行业特性合理调整折现率，通常不低于8%。

### 6.4 忽略企业质地
- **表现**：仅关注估值指标，忽略企业的商业模式、护城河和管理层。
- **风险**：买入低估值但质地差的企业，长期投资回报不佳。
- **规避方法**：估值是企业分析的一部分，需结合企业质地综合判断。

### 6.5 频繁调整估值
- **表现**：根据短期业绩波动频繁调整估值参数。
- **风险**：陷入短期思维，忽略企业长期价值。
- **规避方法**：估值应基于企业长期发展趋势，避免短期噪音干扰。

## 7. 估值实践建议

### 7.1 建立估值记录
- **结构化记录**：记录DCF计算过程、关键假设和敏感性分析，避免只保留最终估值结论。
- **参数记录**：记录每次估值的参数假设，便于后续对比和调整。
- **定期更新**：每季度或半年更新一次估值，根据最新财务数据调整参数。

### 7.2 结合多种估值方法
- **DCF为主**：以自由现金流折现法作为主要估值方法。
- **相对估值为辅**：使用PE、PB等相对估值方法作为参考。
- **交叉验证**：多种方法结果相互验证，提高估值准确性。

### 7.3 关注安全边际
- **匹配不确定性**：现金流越不稳定、估值区间越宽，要求的安全边际越高；不要机械使用统一的50%折扣。
- **分批决策**：只有在事实更新后原判断仍成立时才重新评估；价格下跌本身不是加仓理由。
- **耐心等待**：等待合适的买入时机，避免追高。

### 7.4 长期跟踪企业
- **定期分析**：定期分析企业的财务数据和经营状况，更新估值模型。
- **关注变化**：关注企业基本面的变化，如商业模式调整、管理层变动等。
- **及时调整**：当企业基本面发生重大变化时，及时调整估值和投资策略。

## 8. 估值 Checklist

### 8.1 自由现金流计算
- [ ] 是否使用扣除非经常性损益后的净利润？
- [ ] 是否正确计算折旧摊销、资本开支和营运资金增加？
- [ ] 对于稳定企业，是否使用简化公式？

### 8.2 增长率假设
- [ ] 预测期增长率是否合理，是否参考历史业绩？
- [ ] 永续增长率是否在3%-5%之间？
- [ ] 是否考虑了行业周期和企业发展阶段？

### 8.3 折现率选择
- [ ] 折现率是否考虑了企业风险和行业特性？
- [ ] 折现率是否不低于8%？
- [ ] 是否对不同类型的企业使用不同的折现率？

### 8.4 安全边际
- [ ] 是否根据估值区间和不确定性设置安全边际？
- [ ] 是否设置了基本面失效、机会成本和显著高估等退出条件？
- [ ] 是否考虑了分批建仓策略？

### 8.5 综合判断
- [ ] 是否结合企业的商业模式、护城河和管理层进行分析？
- [ ] 是否使用多种估值方法交叉验证？
- [ ] 是否定期更新估值模型，根据最新数据调整参数？
