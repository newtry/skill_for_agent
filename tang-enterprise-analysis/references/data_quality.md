## 1. 来源优先级

按以下顺序取数，并保留原始出处：

1. 交易所公告、法定披露文件、审计年报。
2. 公司投资者关系网站、业绩公告和正式演示材料。
3. 监管机构或行业协会数据。
4. 可靠第三方数据库，仅用于交叉核验或市场数据。
5. 新闻、研报和搜索摘要只作为线索，不作为关键财务数字的唯一来源。

发生冲突时，以更新的法定披露为准，并说明重述、口径变化或冲突原因。当前价格、汇率、利率和股本必须标注日期。

## 2. 数据记录格式

为每个关键字段保留如下记录：

```json
{
  "metric": "归属于母公司股东的净利润",
  "value": 100.0,
  "unit": "亿元",
  "currency": "CNY",
  "period": "2025年度",
  "scope": "合并",
  "kind": "reported",
  "source": "2025年年度报告",
  "page": 123,
  "confidence": "high"
}
```

`kind` 只能是：

- `reported`：原始披露值。
- `calculated`：由披露值计算，附公式和输入。
- `assumption`：预测假设，附依据和适用情景。

不要用 `0` 表示缺失。缺失值使用 `null`、`N/A` 或“未取得”。

## 3. 口径核验

使用数据前逐项确认：

- 公司主体、股票代码和上市地一致。
- 年度、季度、TTM或单季度口径一致。
- 合并报表与母公司报表没有混用。
- 归母净利润与包含少数股东损益的净利润没有混用。
- 原币、人民币、港币、元、千元、万元、百万元和亿元换算正确。
- 期末余额和期间发生额没有混用。
- 本期列和上期比较列没有混用。
- 股本使用与估值日期相匹配的稀释后或实际口径。
- 重述数据优先于原披露数据。

对关键等式做交叉校验：

```text
资产约等于负债加所有者权益
毛利润约等于营业收入减营业成本
现金期末余额与现金流量表勾稽
每股价值乘股本约等于股权价值
```

允许舍入差异，但必须解释重大不一致。

## 4. 自动提取规则

PDF或脚本输出属于候选数据，不是最终证据。自动提取后至少完成：

1. 对照原表标题，确认合并/母公司和报告期间。
2. 对照表头，确认本期列和单位。
3. 对收入、归母净利润、经营现金流、总资产、净资产和资本开支逐项复核。
4. 保存来源页码；无法定位来源页时将置信度降为 `low`。
5. 与报告摘要或另一可靠来源交叉核验。

扫描件、复杂跨页表格、无法识别单位或多列歧义时改为人工读取，不得靠“取最大值”选择数据。

## 5. 停机条件

出现以下任一情况时，停止精确估值并输出待核查项：

- 公司或证券身份有歧义。
- 核心财务输入缺失或只有低置信度自动提取值。
- 期间、币种、单位或合并口径不能统一。
- 金融企业却只有普通企业经营现金流DCF输入。
- 折现率不高于永续增长率。
- 股本、净债务或当前价格缺少日期。
- 数据源之间存在重大冲突且无法解释。

## 6. 报告披露要求

报告末尾列出：

- 分析截止日期。
- 使用的报告期间和币种。
- 核心来源及链接或页码。
- 主要计算公式。
- 所有估值假设及其情景。
- 缺失数据、低置信度字段和待核查问题。

引用历史案例时明确标记“历史示例”，不要把旧数据写成当前事实。
