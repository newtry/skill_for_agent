## 分析框架总览

### 唐朝六步分析框架

```
Step 0: ROE路标筛选 → Step 1: 商业模式分析 → Step 2: 护城河分析
    ↓
Step 3: 管理层分析 → Step 4: 财报解读 → Step 5: 估值计算
    ↓
Step 6: 投资决策
```

### 唐朝三问（核心检验）

| 问题 | 检验内容 | 关键指标 |
|------|---------|---------|
| **这个生意赚钱吗？** | 盈利能力 | 毛利率、净利率、ROE |
| **赚的是真钱吗？** | 利润质量 | 经营现金流、应收账款、付款条件 |
| **能持续赚钱吗？** | 可持续性 | 护城河、行业地位、管理层 |
| **维持盈利需要大量资本投入吗？** | 资本效率 | 自由现金流、资本开支 |

### 企业分类标准

| 类型 | 特征 | ROE标准 | 投资策略 |
|------|------|---------|---------|
| **完美商业模式** | 高毛利、高净利、高ROE、现金流优秀、护城河宽 | ≥30% | 重仓持有，持有一辈子 |
| **优秀企业** | 有护城河、现金流好 | ≥20% | 重点配置，长期持有 |
| **良好企业** | 有一定护城河 | ≥15% | 适度配置，需低估值保护 |
| **周期性企业** | 盈利波动大 | 周期均值 | 逆向操作，不长期持有 |
| **成长型企业** | 高增长、高风险 | 不确定 | 卫星配置，控制仓位 |

## 案例一：贵州茅台 - 完美商业模式

### 企业概况

| 项目 | 内容 |
|------|------|
| **股票代码** | 600519.SH |
| **主营业务** | 高端白酒生产销售 |
| **核心产品** | 飞天茅台 |
| **企业类型** | 完美商业模式（老天爷赏饭吃） |

### Step 0: ROE路标筛选

#### 近十年ROE数据

| 年份 | ROE | 毛利率 | 净利率 | 经营现金流/净利润 |
|------|-----|--------|--------|------------------|
| 2014 | 31.9% | 92.6% | 51.5% | 108% |
| 2015 | 32.2% | 92.2% | 50.4% | 112% |
| 2016 | 32.8% | 91.2% | 46.1% | 118% |
| 2017 | 32.9% | 89.8% | 49.2% | 105% |
| 2018 | 34.5% | 91.1% | 51.4% | 106% |
| 2019 | 33.1% | 91.3% | 51.5% | 109% |
| 2020 | 31.4% | 91.4% | 48.1% | 102% |
| 2021 | 29.9% | 91.5% | 52.0% | 107% |
| 2022 | 31.2% | 91.9% | 52.0% | 105% |
| 2023 | 32.0% | 91.8% | 52.1% | 107% |

**唐朝解读：**
> "茅台近十年ROE均值32.9%，持续保持在30%以上。这是什么概念？这是唐朝重仓标准。历史ROE就像路标，指引我们发现优质企业。"

#### 筛选结论

| 指标 | 标准 | 茅台数据 | 结论 |
|------|------|---------|------|
| ROE | ≥15% | 32% | ✓ 远超标准 |
| 经营现金流/净利润 | ≥1 | 107% | ✓ 利润真实 |
| 有息负债率 | <50% | <5% | ✓ 几乎无负债 |

**结论：通过ROE路标筛选，进入深度分析**

### Step 1: 商业模式分析

#### 第一部分：定性分析

**1.1 核心业务识别**

| 问题 | 回答 |
|------|------|
| 这家公司是做什么的？ | 生产销售高端白酒，主打飞天茅台 |
| 一句话描述 | 茅台通过传统工艺为消费者提供高端白酒 |
| 业务复杂度 | 简单（核心业务占比>95%） |

**唐朝解读：**
> "茅台的业务很简单：生产白酒，卖给经销商和消费者。就这么简单。如果你不能用一句话说清楚一家公司是做什么的，那这家公司要么商业模式太复杂，要么业务太分散，投资风险都很大。"

**1.2 盈利模式分析**

| 指标 | 茅台数据 | 行业平均 | 评价 |
|------|---------|---------|------|
| 毛利率 | 91.8% | 70% | 极强定价权 |
| 净利率 | 52.1% | 25% | 盈利能力极强 |
| ROE | 32% | 18% | 顶级水平 |

**ROE分解（杜邦分析）：**

```
ROE = 净利率 × 资产周转率 × 权益乘数
32% = 52% × 0.5 × 1.3

结论：茅台的高ROE完全来自高净利率，这是最高质量的ROE来源
```

**唐朝解读：**
> "茅台的毛利率91.8%，这是什么概念？卖100块钱的酒，成本只有8块多。这说明茅台有极强的定价权，消费者愿意为品牌买单。高净利率驱动的ROE，是最优质的ROE。"

**1.3 业务持续性评估**

| 评估维度 | 分析 |
|---------|------|
| 行业生命周期 | 成熟期，需求稳定 |
| 技术迭代风险 | 极低，工艺百年不变 |
| 行业增长空间 | 有限但稳定，年增长5-10% |

**唐朝解读：**
> "白酒行业是成熟期，增长有限但稳定。技术变化慢的行业，今天的护城河明天还在。茅台的工艺几百年不变，护城河非常稳定。"

#### 第三部分：财报验证

**3.1 利润真实性检验**

| 检验项 | 标准 | 茅台数据 | 结论 |
|--------|------|---------|------|
| 经营现金流/净利润 | >1 | 107% | ✓ 优秀 |
| 销售现金/营业收入 | >1 | 117% | ✓ 优秀 |
| 应收账款/营业收入 | <10% | <1% | ✓ 完美 |
| 应收账款增速 | ≤营收增速 | 无应收 | ✓ 完美 |

**唐朝解读：**
> "经营现金流持续大于净利润，才是真赚钱。茅台的经营现金流/净利润=107%，应收账款几乎为零。这是100%真金白银。"

| 检验项 | 标准 | 茅台数据 | 结论 |

| 主营业务收入占比 | >0.95 | 98% | ✓ 优秀 |
| 毛利率稳定性 | 稳定 | 91-92% | ✓ 稳定 |

**唐朝解读：**
> "一定要看扣非净利润。茅台的扣非净利润占比99%，利润全部来自主营业务。这才是公司真本事。"

**3.3 资产质量检验**

| 检验项 | 茅台数据 | 评价 |
|--------|---------|------|
| 应收账款/总资产 | <1% | 优秀 |

| 商誉/净资产 | 0 | 无风险 |
| 其他应收款/总资产 | <1% | 无风险 |

**唐朝解读：**

### Step 5: 估值计算

#### 自由现金流折现法（DCF）

**Step 1: 确定基准年自由现金流**

| 项目 | 数据 | 说明 |
|------|------|------|
| 基准年 | 2023年 | |
| 经营活动现金流净额 | 约666亿元 | |
| 资本开支 | 约40亿元 | |
| **基准年FCF** | **626亿元** | 666-40=626 |

**唐朝解读：**
> "茅台满足三大前提：利润为真、可持续、无需大量资本支出。在这种情况下，可以直接用净利润作为自由现金流的近似值。但为了保守，我们用经营现金流减去资本开支。"

**Step 2: 预测未来现金流**

| 参数 | 数值 | 说明 |
|------|------|------|
| 预测期 | 10年 | 稳定成长型企业 |
| 前5年增长率 | 10% | 保守估计 |
| 后5年增长率 | 5% | 逐步放缓 |
| 永续增长率 | 3% | 无风险利率水平 |

**Step 3: 确定折现率**

| 参数 | 数值 | 说明 |
|------|------|------|
| 无风险利率 | 3% | 10年期国债收益率 |
| 风险溢价 | 7% | 茅台风险低，溢价适中 |
| **折现率** | **10%** | 常用基准值 |

**Step 4: 计算现值**

```
预测期现值计算（2024-2033年）：

年份    FCF(亿)   折现因子   现值(亿)
2024    689       0.909     626
2025    758       0.826     626
2026    834       0.751     627
2027    917       0.683     626
2028    1009      0.621     627
2029    1059      0.564     597
2030    1112      0.513     570
2031    1168      0.467     545
2032    1226      0.424     520
2033    1287      0.386     497

预测期现值合计：约5761亿元

永续期现值计算：
永续期现值 = 1287 × (1+3%) / (10%-3%) = 18951亿元
折现到2023年 = 18951 × 0.386 = 7315亿元

企业内在价值 = 5761 + 7315 = 13076亿元
```

**Step 5: 确定买入/卖出价格**

| 项目 | 计算 | 结果 |
|------|------|------|
| 企业内在价值 | 13076亿元 | |
| 总股本 | 12.56亿股 | |
| **每股内在价值** | 13076/12.56 | **约1040元** |
| **理想买入价** | 1040 × 50% | **≤520元** |
| **理想卖出价** | 1040 × 150% | **≥1560元** |

**历史案例说明：**
> 上表展示原方法的固定安全边际规则，只用于解释历史框架。实际使用必须更新数据并按估值区间和不确定性确定安全边际。

## 案例四：康美药业 - 造假案例警示

### 案例背景

康美药业曾是A股医药白马股，2018年被发现财务造假，涉及金额高达300亿元，成为中国资本市场最大的财务造假案之一。

### 造假信号回顾

#### 信号一：货币资金异常

| 信号 | 数据 | 唐朝解读 |
|------|------|---------|
| 货币资金 | 300亿 | 账上有很多钱 |
| 有息负债 | 200亿 | 同时借了很多钱 |
| 货币资金收益率 | 远低于银行存款 | 钱可能是假的 |

**唐朝警示：**
> "康美药业账上有300多亿货币资金，但同时有200多亿有息负债。这完全不合逻辑——有钱不还债，反而借钱付利息？后来证明这300亿货币资金是假的。"

#### 信号二：现金流与利润背离

| 指标 | 数据 | 危险程度 |
|------|------|---------|
| 经营现金流/净利润 | <0.5 | 高危险 |
| 应收账款/营收 | >50% | 高危险 |
| 存货增速 | >>营收增速 | 中危险 |

**唐朝警示：**
> "经营现金流/净利润<0.5，这是危险信号。利润表好看，但现金流量表不好看。利润可以调节，但现金流难以造假。"

#### 信号三：其他应收款异常

| 指标 | 数据 | 危险程度 |
|------|------|---------|
| 其他应收款/总资产 | >10% | 高危险 |
| 关联方资金占用 | 巨大 | 极高危险 |

**唐朝警示：**
> "其他应收款是个垃圾筐，什么都能往里装。其他应收款/总资产>10%的公司，要非常小心。"

### 红旗信号汇总

| 信号类别 | 红旗信号 | 康美数据 | 危险程度 |
|---------|---------|---------|---------|
| 货币资金 | 货币资金多但有息负债也多 | 300亿+200亿 | 极高 |
| 货币资金 | 货币资金收益率异常低 | 远低于存款利率 | 高 |
| 现金流 | 经营现金流/净利润 < 0.5 | <0.5 | 高 |
| 应收账款 | 应收账款/营收 > 50% | >50% | 高 |
| 其他应收款 | 其他应收款/总资产 > 10% | >10% | 高 |

**唐朝原则：**
> "发现一个红旗信号，要提高警惕；发现两个红旗信号，要深入调查；发现三个以上红旗信号，直接放弃。康美药业有五个红旗信号，应该直接回避。"

### 教训总结

| 教训 | 说明 |
|------|------|
| **现金流是核心** | 利润可以是假的，现金流是真的 |
| **交叉验证** | 货币资金要与有息负债、收益率交叉验证 |
| **关注异常** | 任何不合逻辑的数据都要警惕 |
| **相信常识** | 有钱不还债反而借钱，不合常识 |

**唐朝总结：**
> "财报是用来排除企业的。康美药业的造假信号非常明显：货币资金多但有息负债也多、货币资金收益率异常低、经营现金流/净利润<0.5。只要认真看财报，这些信号都能发现。投资最重要的不是赚多少，而是不亏钱。"

| **长期投资** | 投资是时间的朋友，优质企业应持有3-5年以上 |
| **价值投资** | 价格相对保守估值具备与不确定性匹配的安全边际 |
| **风险控制** | 安全边际+适度分散+坚守能力圈 |
| **逆向思维** | 别人恐惧我贪婪，别人贪婪我恐惧 |
| **排除法** | 财报是用来排除企业的，不是用来选择企业的 |

## 企业分析Checklist（唐朝标准）

### Step 0: ROE筛选

- [ ] 近5年ROE是否持续≥15%？
- [ ] 经营现金流是否≥净利润？
- [ ] 有息负债是否过高？

### Step 1: 商业模式（唐朝三问）

- [ ] **这个生意赚钱吗？**
  - 毛利率>40%？
  - 净利率>15%？
  - ROE>15%？
  - ROE来源是高净利率吗？

- [ ] **赚的是真钱吗？**
  - 经营现金流/净利润≥1？
  - 销售现金/营业收入≥1？
  - 应收账款/营业收入<30%？
  - 付款条件是什么？（先款后货最好）

- [ ] **能持续赚钱吗？**
  - 有明确的护城河吗？
  - 护城河可持续吗？
  - 行业地位稳固吗？
  - 管理层诚信吗？

- [ ] **维持盈利需要大量资本投入吗？**
  - 固定资产周转率高吗？
  - 资本开支/净利润<50%？
  - 自由现金流为正吗？

### Step 2: 护城河

- [ ] 是否有明显的竞争优势？
- [ ] 护城河是否可持续？
- [ ] 与竞争对手相比优势是否明显？

### Step 3: 管理层

- [ ] 管理层是否诚信？
- [ ] 历史业绩是否优秀？
- [ ] 分红政策是否稳定？
- [ ] 资本配置是否理性？

### Step 4: 财报

- [ ] 利润真实性是否通过检验？
- [ ] 利润可持续性是否良好？
- [ ] 资产质量是否健康？
- [ ] 有无地雷（应收、商誉、其他应收）？

### Step 5: 估值

- [ ] 是否选择了适用于该行业的估值方法？
- [ ] 是否按估值区间和不确定性设置安全边际？
- [ ] 是否设置了基本面失效和显著高估等退出条件？

### Step 6: 投资决策

- [ ] 是否在能力圈内？
- [ ] 仓位控制是否合理？
- [ ] 是否符合核心-卫星配置策略？
- [ ] 是否严格执行投资纪律？
