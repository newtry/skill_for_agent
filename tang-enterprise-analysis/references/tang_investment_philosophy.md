## 一、价值投资四大基石

### 1.1 格雷厄姆三大原则

格雷厄姆投资体系的三大核心原则，是价值投资的根基：

#### 原则一：股票是企业部分所有权的凭证
- **核心思想**：买股票就是买公司，而非买筹码
- **唐朝解读**：
  - 股票可拆解为"股"+"票"
  - "股"：股权凭证属性，代表企业部分所有权
  - "票"：交易票据属性，作为交易凭证在市场流通
- **实践意义**：
  - 关注企业内在价值，而非短期价格波动
  - 以企业所有者的心态思考投资决策
  - 长期持有优质企业，分享企业成长

#### 原则二：无情地利用市场先生的报价
- **核心思想**：市场是仆人而非主人，利用情绪而非被情绪左右
- **唐朝解读**：
  - 市场先生每天给你报价，他情绪不稳定
  - 有时亢奋，有时恐慌
  - 你可以利用他的愚蠢，而不是被他影响
- **实践意义**：
  - 不要被市场情绪左右
  - 市场恐慌时买入，市场亢奋时卖出
  - 遵循"别人恐惧我贪婪，别人贪婪我恐惧"

#### 原则三：坚持买入时的安全边际原则
- **核心思想**：预留足够的缓冲空间应对不确定性
- **唐朝解读**：
  - 安全边际是价值投资的核心
  - 哪怕你看错了，安全边际也能保护你
  - 买入价格需低于内在价值的50%
- **实践意义**：
  - 留出足够缓冲空间应对不确定性
  - 降低判断失误带来的损失
  - 提高投资成功率

### 1.2 巴菲特新增原则：能力圈原则

巴菲特在格雷厄姆三大原则基础上，增加了能力圈原则：

#### 能力圈原则
- **核心思想**：只投资自己能够理解的企业，不懂不做
- **唐朝解读**：
  - 将企业简单划分为八类
  - 只对①买入、②卖出的甜蜜区出手
  - 不懂不做，坚守能力圈
- **实践意义**：
  - 避免在不懂的领域犯错
  - 专注于自己理解的企业
  - 持续学习，逐步拓展能力圈边界

## 二、选股核心指标：ROE（净资产收益率）

### 2.1 ROE是路标

- **唐朝观点**：历史净资产收益率就像路标，指引我们去发现那些具备高经济商誉以及低有形资产的优质企业
- **为什么是ROE？**
  - ROE反映企业运用净资产盈利的能力
  - 高ROE通常意味着企业有某种竞争优势
  - 持续高ROE是优质企业的重要特征

### 2.2 ROE标准

| ROE水平 | 评级 | 说明 |
|---------|------|------|
| ≥30% | 顶级 | 唐朝重仓标准 |
| ≥20% | 优秀 | 值得重点关注 |
| ≥15% | 良好 | 可以纳入观察 |
| <10% | 一般 | 通常不考虑 |

### 2.3 在高ROE基础上

在拥有高股权回报率的基础之上，再进一步开始考量：
1. **生意模式**：商业模式是否简单易懂、盈利稳定
2. **护城河**：企业是否有持续的竞争优势
3. **盈利质量**：利润是否真实、是否可持续

## 三、企业分析三大核心要素

### 3.1 商业模式（生意模式）

#### 选择标准
- 简单易懂
- 盈利稳定
- 持续成长

#### 唐朝三问（商业模式检验）

**问题一：这个生意赚钱吗？**
- 看毛利率：是否足够高且稳定
- 看净利率：净利润率是否优秀
- 看ROE：净资产收益率是否持续高位

**问题二：赚的是真钱吗？**
- 看现金流：经营现金流是否持续大于净利润
- 看付款条件：是先款后货还是有账期
- 看应收账款：应收账款占比是否合理、增速是否过快

**问题三：能持续赚钱吗？**
- 看护城河：企业是否有持续的竞争优势
- 看行业地位：企业在行业中的地位是否稳固
- 看管理层：管理层是否诚信、能力是否出众

### 3.2 护城河（竞争壁垒）

#### 常见护城河类型

| 护城河类型 | 说明 | 代表企业 |
|-----------|------|---------|
| 品牌优势 | 品牌溢价、用户心智占领 | 贵州茅台 |
| 网络效应 | 越多用户使用，价值越大 | 腾讯 |
| 成本优势 | 规模效应、成本控制能力 | 某些制造业 |
| 技术专利 | 技术壁垒、专利保护 | 某些高科技企业 |
| 行政许可 | 牌照、资质准入 | 某些金融、公用事业 |
| 转换成本 | 用户切换成本高 | 某些软件企业 |

#### 护城河评估要点
- 护城河宽度：竞争优势有多强
- 护城河可持续性：竞争优势能维持多久
- 护城河可复制性：竞争对手是否容易模仿

### 3.3 管理层

#### 评估维度
- **诚信**：管理层是否诚信正直
- **能力**：管理层能力是否出众
- **股东回报意识**：是否以股东利益为重
- **资本配置能力**：是否理性配置资本

#### 好管理层的特征
- 诚信正直，不说假话
- 能力出众，能带领企业发展
- 以股东利益为重，重视分红
- 理性配置资本，不乱投资

## 四、投资心态

### 4.1 长期持有

#### 核心观点
- 反对频繁交易
- 主张持有3-5年以上
- 享受企业成长和复利收益

#### 持股时间
- 优质企业应该持有一辈子（如果企业基本面不变）
- 不要因为短期波动而卖出
- 除非企业基本面恶化或发现更好的标的

### 4.2 逆向思维

#### 核心观点
- 市场恐慌时买入
- 市场亢奋时卖出
- 遵循"别人恐惧我贪婪，别人贪婪我恐惧"

#### 利用市场先生
- 市场先生每天给你报价
- 你可以利用他的愚蠢，而不是被他影响
- 不要被市场情绪左右

## 五、风险控制

### 5.1 安全边际

#### 核心观点
- 买入价格需低于内在价值的50%
- 留出足够缓冲空间应对不确定性
- 安全边际是价值投资的核心

#### 为什么需要安全边际？
- 人的判断可能出错
- 企业经营可能出现意外
- 市场可能长期非理性
- 哪怕你看错了，安全边际也能保护你

### 5.2 适度分散

#### 核心观点
- 核心持仓不超过5-8只
- 单只股票占比不超过总仓位的40%
- 三五个行业、七八个企业

#### 分散的意义
- 降低单一股票风险
- 避免黑天鹅事件
- 保持心态稳定

### 5.3 能力圈

#### 核心观点
- 只投资自己能够理解的企业
- 不懂不做，坚守能力圈
- 持续学习，逐步拓展能力圈边界

#### 如何坚守能力圈？
- 承认自己的无知
- 不跟风投资
- 不懂的企业坚决不碰
- 持续学习，逐步拓展

## 六、估值方法：自由现金流折现

### 6.1 核心公式

#### 自由现金流（FCF）

**完整公式**：
```
FCF = 净利润 + 折旧摊销 - 资本开支 - 营运资金增加
```

**稳定企业简化**：
```
FCF = 净利润 ×（1 - 分红率）
```

### 6.2 预测未来现金流

#### 预测期
- 未来5-10年增长率
- 基于历史业绩和行业空间

#### 永续期
- 之后进入永续增长期
- 增长率接近无风险利率，如3%-5%

### 6.3 折现计算内在价值

#### 折现率
- 使用无风险利率（如10年期国债收益率）

#### 内在价值
- 将未来现金流折现为现值
- 即为企业内在价值

### 6.4 确定买卖点

#### 买入
- 价格 < 内在价值 × 50%

#### 卖出
- 价格 > 内在价值 × 150%
- 或企业基本面恶化

## 七、企业分类与投资策略

### 7.1 完美商业模式（老天爷赏饭吃）

#### 特征
- 高毛利
- 高净利
- 高ROE
- 现金流优秀
- 护城河宽

#### 代表企业
- 贵州茅台

#### 投资策略
- 重仓持有
- 只要基本面不变就持有一辈子

### 7.2 优秀企业

#### 特征
- ROE持续20%以上
- 有一定护城河

#### 投资策略
- 重点关注
- 合理价格买入

### 7.3 普通企业

#### 特征
- ROE在10%-20%之间
- 护城河较弱

#### 投资策略
- 需要有强护城河和低估值才考虑

### 7.4 周期性企业

#### 特征
- 盈利波动大
- 与宏观经济高度相关

#### 投资策略
- 使用周期均值法估值
- 谨慎投资

## 八、投资决策清单

### 8.1 买入决策检查清单

- [ ] 企业过去5年ROE持续≥15%？
- [ ] 企业商业模式简单易懂？
- [ ] 企业有明显的护城河？
- [ ] 管理层诚信、能力出众？
- [ ] 利润真实、经营现金流持续≥净利润？
- [ ] 企业在我的能力圈内？
- [ ] 当前价格低于内在价值的50%？
- [ ] 有足够的安全边际？

### 8.2 持有决策检查清单

- [ ] 企业基本面未发生根本性恶化？
- [ ] 价格未超过内在价值的150%？
- [ ] 没有发现更好的投资标的？
- [ ] 企业仍在我的能力圈内？

### 8.3 卖出决策检查清单

- [ ] 企业基本面恶化（护城河消失、管理层变质）？
- [ ] 价格超过内在价值的150%？
- [ ] 发现更好的投资标的（机会成本）？
- [ ] 发现自己当初判断错误？
- [ ] 企业超出能力圈范围？

## 九、经典案例：贵州茅台

### 9.1 为什么茅台是完美商业模式？

#### 高ROE
- 近十年ROE均值为32.9%
- 持续保持在30%以上

#### 高毛利、高净利
- 毛利率超过90%
- 净利率超过50%

#### 现金流优秀
- 先款后货，预收款多
- 经营现金流持续大于净利润

#### 护城河宽
- 品牌优势强
- 地理位置独特
- 工艺独特，难以复制

### 9.2 投资策略

- 重仓持有
- 只要基本面不变就持有一辈子
- 忽略短期波动

## 十、总结与实践建议

### 10.1 投资成功的关键

1. **理解投资本质**：买股票就是买公司
2. **坚守能力圈**：不懂不做
3. **寻找优质企业**：高ROE、好商业模式、宽护城河
4. **安全边际**：价格低于内在价值50%才买入
5. **长期持有**：忽略短期波动，享受企业成长
6. **利用市场先生**：市场恐慌时买入，市场亢奋时卖出

### 10.2 学习路径建议

1. **先读**：《价值投资实战手册》理解投资思想
2. **再读**：《手把手教你读财报》学习财报分析
3. **深读**：《巴芒演义》理解投资大师的思想演变
4. **实践**：用tang-enterprise-analysis技能分析企业
5. **持续学习**：不断拓展能力圈，提升分析能力
