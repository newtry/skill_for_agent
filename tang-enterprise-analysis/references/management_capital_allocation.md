# 管理层、治理与资本配置

## 目录

1. 识别关键决策者

## 1. 识别关键决策者

核查实际控制人、主要股东、董事长、CEO或总经理、CFO和核心业务负责人。记录任期、职责、持股和重要变化。不要把创始人、控股股东和职业经理人的责任混在一起。

## 2. 经营能力

用任期内结果而不是语言评价：

- 市场份额、客户、产品和单位经济模型。
- 收入、经营利润、现金流和ROIC。
- 增量资本回报与竞争优势变化。
- 对周期、危机、监管和技术变化的应对。
- 经营目标兑现率及失败后的纠偏。

区分行业顺风与管理能力。将结果与同行、行业和接任前基线比较。

## 3. 诚信与治理

检查：

- 信息披露是否清晰、稳定且可勾稽。
- 监管处罚、财务重述、审计意见和内控缺陷。
- 关联交易、资金占用、担保和利益输送。
- 业绩承诺、指引和实际结果的偏差。
- 重大负面事件是否及时披露并承担责任。

没有负面记录不等于已经证明诚信。只能根据已核查证据给出有限判断。

## 4. 资本配置

按用途检查每一单位留存利润：

| 用途 | 价值创造条件 | 风险信号 |
|---|---|---|
| 主业再投资 | 增量ROIC高于资本成本 | 产能闲置、低回报扩张 |
| 研发与品牌 | 可观察的产品、留存或价格权 | 长期投入无产出且口径变化 |
| 并购 | 价格合理、协同兑现、整合成功 | 高溢价、跨界、持续减值 |
| 偿债 | 降低脆弱性或高成本债务 | 有能力偿债却维持复杂融资 |
| 分红 | 缺少高回报再投资机会 | 借债分红、削弱资本缓冲 |
| 回购 | 价格低于保守价值且抵消真实稀释 | 高估回购、只抵消股份支付 |

计算并购后的投入资本回报，检查商誉和减值。分红率和回购金额不能脱离再投资机会、资产负债表和价格评价。

## 5. 利益一致性

核查持股、增减持、质押、薪酬、股权激励和考核指标。重点判断激励是否鼓励收入规模、短期利润、ROIC、现金流或每股价值。

高持股不自动等于利益一致；控股股东也可能通过关联交易、资产注入或融资安排损害少数股东。

## 6. 接班与组织

检查企业是否依赖单一人物，核心团队是否稳定，人才和决策机制能否复制。关注关键人离任、组织频繁调整、文化失效和接班计划。

## 7. 证据模板

```markdown
## 管理层判断
结论及置信度。

## 经营记录
任期、基线、同行对比、成功与失败。

## 资本配置
再投资、并购、分红、回购、偿债及增量回报。

## 治理与一致性
关联交易、处罚、激励、增减持和接班风险。

## 反方证据与待核查
列出可能推翻判断的事实。
```
