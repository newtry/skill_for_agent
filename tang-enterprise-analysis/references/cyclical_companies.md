# 周期企业分析与估值

## 1. 识别周期来源

区分商品价格、产能、库存、资本开支、宏观需求、利率、运价和政策周期。说明企业是价格接受者还是具有产品差异化。

周期性不是股价波动，而是经营现金流和资本回报由外部供需反复驱动。

## 2. 正常化盈利

不要用周期顶部或底部单年利润外推。覆盖尽可能完整的周期，分解：

```text
收入 = 销量 × 实现价格
单位利润 = 实现价格 - 单位现金成本 - 维持性投入
```

使用中枢价格、正常产能利用率、正常成本和税费构建情景。检查企业扩产是否改变未来供给和自身成本。

## 3. 资产负债表

重点检查：

- 现金成本和盈亏平衡点。
- 净债务、债务期限、契约和再融资。
- 维持性资本开支、环保和安全投入。
- 存货计价、资源储量、资产减值和复垦义务。
- 周期底部是否仍能覆盖利息和必要投入。

能穿越周期的资产负债表通常比顶部利润增速更重要。

## 4. 供需与成本曲线

分析行业产能、在建项目、退出壁垒、库存、需求弹性和边际生产者。定位企业在成本曲线中的位置，并验证成本优势是否来自资源禀赋、规模、物流或短期因素。

高商品价格会刺激供给与替代，低价格会延迟投资和淘汰高成本产能。预测必须包含这种反馈。

## 5. 估值

优先方法：

- 周期中枢FCFF或正常化利润。
- 资产净值、储量价值或重置成本。
- EV/正常化产能、产量或EBIT作为交叉验证。

至少建立低、中、高价格情景，并联动销量、成本、资本开支、税费和资产负债表。不要用当前现货价格作为永续价格。

对于资源企业，说明储量、品位、开采年限、特许权使用费和复垦成本。对于航运、化工和钢铁，说明订单、产能投放和退出速度。

## 6. 失效条件

- 成本曲线位置恶化。
- 高杠杆导致底部被迫融资或稀释。
- 扩产、替代技术或政策永久改变供需。
- 储量、品位、产能或环保义务被错误估计。
- 管理层在顶部进行高价扩张或并购。
